## 🌀 What Even IS This

You know that thing where you're sad but you don't know what to listen to so you scroll Spotify for 40 minutes and end up just playing the same 3 songs you always play? Yeah. Moodify_AI looked at that and said *"not on my watch."*

Moodify_AI is a full-stack web application that detects your **emotional state** using the dark arts of artificial intelligence and then — in an act of profound digital compassion — recommends music that matches your mood. It does this without judgment. It does not care that you're listening to sad boy indie at 2pm on a Tuesday. It respects you.

**Tech stack, for the curious and the suspicious:**
- 🟨 **JavaScript** (67.6%) — the chaotic neutral of programming languages
- 💅 **SCSS** (31.9%) — because plain CSS is for cowards
- 🧱 **HTML** (0.5%) — the skeleton that holds the skin on

---

## 🏗️ Architecture (or: How the Sausage Gets Made)

```
Moodify_AI/
├── Backend/      ← where the AI does its mysterious whispering
└── Frontend/     ← where the pixels put on a pretty dress
```

The **Backend** processes your soul (technically: your mood input) and figures out what you're feeling.

The **Frontend** presents this information to you in a way that doesn't make you feel like you're being watched by a robot.

*(You are being watched by a robot. A friendly one.)*

## 🚀 Getting Started

### Prerequisites

Before you begin, please ensure you have the following:

- Node.js installed
- npm or yarn (pick one, commit to it, no wishy-washy)
- A mood (any mood is acceptable — even "vaguely unsettled" works)
- The will to live, or at least to run `npm install`

### Installation

```bash
# Step 1: Clone the repository into your heart (and also your hard drive)
git clone https://github.com/Rajkamal017/Moodify_AI.git
cd Moodify_AI

# Step 2: Install Backend dependencies
cd Backend
npm install

# Step 3: Install Frontend dependencies
cd ../Frontend
npm install

# Step 4: Stare at the node_modules folder and contemplate the universe
```

### Running the App

```bash
# Terminal 1: Wake up the Backend
cd Backend
npm start

# Terminal 2: Wake up the Frontend
cd Frontend
npm start

# Terminal 3: Optional — open another terminal and just vibe
```

## 🎭 How It Works (a dramatic retelling)

1. **You arrive.** Weary. Perhaps emotionally ambiguous.
2. **You interact with the app.** Maybe you type how you feel. Maybe you let the AI look at your face. Either way, you surrender a tiny sliver of your inner life to the machine.
3. **The AI thinks.** It hums quietly to itself in JavaScript. Weights are consulted. Decisions are made in dimensions you cannot perceive.
4. **A mood is classified.** Happy. Sad. Angry. Nostalgic. That specific feeling you get on Sunday evenings when the weekend is almost over. All of them.
5. **Music is recommended.** Curated. Personalized. Eerily on point.
6. **You listen.** A single tear rolls down your cheek, not from sadness, but from the shock of being truly *understood* by software.
